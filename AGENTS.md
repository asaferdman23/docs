# Bizzclaw public docs

Customer-facing docs for Bizzclaw, built with Mintlify. Pages are MDX, config is `docs.json`.

Rules:
- Document only features that are live for every customer. Leave out anything allowlisted, in beta or switched on per account.
- Never name the underlying model, AI company, cloud or tech stack.
- Spell the product "Bizzclaw".
- Preview with `npx mint@latest dev`; check with `npx mint@latest broken-links`.
