Connect tools from your dashboard. Each one signs in through the tool's own login page. Bizzclaw never asks for your password in chat.

**Reading is immediate. Writing follows the [approval rules](/concepts/approvals).**

| Tool | What Bizzclaw can read | What it can do (with approval rules) |
|---|---|---|
| **Google Calendar** | Events, availability | Create, move and update events, change attendees, RSVP. Cancelling always asks. |
| **Gmail** | — | Send email on your behalf. Bizzclaw cannot read your inbox. |
| **HubSpot** | Your CRM records and deals | Changes to records go through approvals |
| **Notion** | Pages and databases | Changes go through approvals |
| **Linear** | Issues and projects | Changes go through approvals |
| **Jira** | Issues and projects | Create issues, comment, move status |
| **GitHub** | Repos, issues, pull requests | Changes go through approvals. Code changes always ask. |
| **Cal.com** | Bookings, event types, free slots | Book and reschedule. Cancelling always asks. |
| **Fireflies** | Meeting transcripts and summaries | — |

## Built in, nothing to connect

- **CRM:** people, deals, pipeline stages, follow-ups and notes, kept by Bizzclaw.
- **Web research:** its own browser to search and read web pages.

## Disconnecting

You can disconnect any tool from the dashboard. Disconnecting stops access going forward; it doesn't by itself delete records Bizzclaw already holds. To request deletion, contact [support@bizz-claw.com](mailto:support@bizz-claw.com).
